Strictly Decoupled Architecture

Never modify upstream files in place. Upstream MeshCore remains an untouched Git submodule, enabling friction-free synchronized updates while preserving all custom Romanian enhancements.

Clean hooks, PA gain limits, geofences, token buckets, and conversational CLI logic compiled via preprocessor feature gates.

Universal PA Gain Limiter

Attenuates SX1262 drive level on 1W boards (T-Beam 1W, RAK 1W) to strictly enforce the +27 dBm ERP / +22 dBm conducted legal boundary.

Output = min(Target, Legal - PA Gain)

Enforces a 10% duty cycle airtime token bucket and universal 24-hour remote advert rate limiting. Rogue flooders are quarantined for 60 minutes.

Protects off-grid solar repeaters. Transmit relaying suspends at 3.40V (passive receive mode) and recovers cleanly at 3.60V.

Command Cheat Sheet

In-Chat & Serial Management

Search commands across companion slash commands and repeater serial CLI.

Interface Command Scope & Description Example
In-Chat /help Displays full companion command list /help
In-Chat /status Diagnostics: battery %, GPS fix, active tier, PA clamp /status
In-Chat /tier [0-3|auto|off] Inspects or overrides repeating delay tier /tier auto
In-Chat /sos [trigger|cancel] Triggers or clears active emergency SOS beaconing /sos cancel
In-Chat /gps Displays coordinates, altitude, sats, and Google Maps URL /gps
In-Chat /battery Detailed LiPo voltage and percentage /battery
Serial get tier Inspects active mode, tier index, and delay seconds get tier
Serial set tier <0-3> Manually locks repeater into designated delay tier set tier 0
Serial set pa.limiter <on|off> Enables or bypasses the PA power limiter set pa.limiter on
Serial set pa.gain <dB> Sets hardware amplifier gain level (e.g. 14 dB) set pa.gain 14
Serial ban list Lists all quarantined nodes and remaining timeout ban list
Serial ban add <hex> <min> Manually puts a node public key into quarantine ban add A1B2C3D4 120
